# Manual do Usuário
## Sistema Inteligente de Controle de Qualidade

### 1. Apresentação
Este sistema tem como objetivo auxiliar o controle
de qualidade por meio do gerenciamento de produtos,
lotes, inspeções e não conformidades.

### 2. Acesso ao sistema
1. Acessar o endereço do sistema.
2. Informar o e-mail cadastrado.
3. Informar a senha.
4. Clicar em entrar.

### 3. Cadastro de produtos
Descrever como acessar a área de produtos e realizar
um novo cadastro.

### 4. Cadastro de lotes
Explicar como cadastrar e consultar lotes.

### 5. Realização de inspeções
Explicar como iniciar uma inspeção e preencher
os critérios de avaliação.

### 6. Não conformidades
Explicar como registrar e acompanhar problemas
identificados durante uma inspeção.

### 7. Relatórios
Explicar como consultar e exportar relatórios.

### 8. Suporte
Informar como entrar em contato com a equipe responsável.
