# Casos de Teste

## CT001 - Login com dados válidos

- Funcionalidade: Login
- Objetivo: Verificar se o usuário consegue acessar o sistema.
- Pré-condição: Usuário cadastrado.

### Passos
1. Acessar a tela de login.
2. Informar um e-mail cadastrado.
3. Informar a senha correta.
4. Clicar em entrar.

### Resultado esperado
O sistema deve autenticar o usuário e permitir seu acesso.

### Resultado obtido
A preencher durante a execução.

### Status
Pendente.

---

## CT002 - Login com senha incorreta

- Funcionalidade: Login
- Objetivo: Verificar o comportamento com senha inválida.

### Passos
1. Acessar a tela de login.
2. Informar um e-mail cadastrado.
3. Informar uma senha incorreta.
4. Tentar entrar.

### Resultado esperado
O sistema deve negar o acesso e apresentar uma mensagem
informando que as credenciais são inválidas.

### Resultado obtido
A preencher durante a execução.

### Status
Pendente.

---

## CT003 - Cadastro de produto com campos obrigatórios vazios

- Funcionalidade: Cadastro de produtos
- Objetivo: Verificar a validação dos campos obrigatórios.

### Passos
1. Acessar o cadastro de produtos.
2. Deixar os campos obrigatórios vazios.
3. Tentar salvar.

### Resultado esperado
O sistema deve impedir o cadastro e informar os campos
que precisam ser preenchidos.

### Resultado obtido
A preencher durante a execução.

### Status
Pendente.
