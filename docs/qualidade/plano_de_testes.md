# Plano de Testes
## Sistema Inteligente de Controle de Qualidade

### 1. Objetivo
Definir como serão realizados os testes do Sistema
Inteligente de Controle de Qualidade, verificando se
suas funcionalidades atendem aos requisitos do projeto.

### 2. Escopo dos testes
Serão avaliadas as seguintes funcionalidades:

- Login e autenticação de usuários;
- Cadastro e consulta de produtos;
- Cadastro e consulta de lotes;
- Gerenciamento de critérios e checklists;
- Registro de inspeções;
- Registro de não conformidades;
- Envio e consulta de evidências;
- Geração de relatórios.

### 3. Tipos de testes
- Testes funcionais: verificar se as funções operam corretamente.
- Testes de validação: verificar campos obrigatórios e dados inválidos.
- Testes de permissões: verificar o acesso de cada tipo de usuário.
- Testes de integração: verificar a comunicação entre as partes do sistema.
